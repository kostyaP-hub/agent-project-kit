# Безопасность конфигов агента

Файлы, которые агент читает как указания, — исполняемая политика, а не документация.
`AGENTS.md`, `CLAUDE.md`, `.claude/`, `.codex/`, `.mcp.json`, `.vscode/mcp.json`,
`.github/copilot-instructions.md` в чужом репозитории могут попросить агента выполнить
команду, отправить данные или запустить сервер инструментов.

## Свой репозиторий

- **MCP не включается клонированием.** Kit поставляет
  [`kit/templates/mcp.example.json`](../kit/templates/mcp.example.json), а не `.mcp.json`.
  Скопируйте его под нужным агенту именем осознанно, после просмотра.
- **Никаких секретов в конфиге.** Только ссылки на переменные окружения (`${DOCS_TOKEN}`).
- **Минимум прав.** Предпочитайте read-only инструменты и локальные команды из репозитория.
  `npx some-server@latest` скачивает и исполняет чужой код при каждом запуске.
- **Изменение конфига агента — защищённый путь.** Такие правки проходят ревью, как CI и миграции.

## Чужой репозиторий

Перед тем как запускать агента в клоне:

1. Прочитайте глазами файлы-инструкции и MCP-конфиги из списка выше.
2. Проверьте настройки Git, которые исполняют команды при работе с клоном, и содержимое
   `.git/hooks/`. Git печатает имена ключей в нижнем регистре, поэтому поиск без учёта регистра:
   `git config --local --list | grep -iE 'fsmonitor|hookspath|sshcommand|pager|external|^filter\.|^include'`
3. Поищите скрытый текст: невидимые Unicode-символы (zero-width, tag characters
   U+E0000–U+E007F), HTML-комментарии, белый текст. Глазами не видно, поиском видно
   (GNU grep в UTF-8 локали; на macOS — `ggrep` из Homebrew). Код выхода 2 — ошибка, а не «чисто»:
   `LC_ALL=C.UTF-8 grep -rnP '[\x{200B}-\x{200F}\x{2060}\x{E0000}-\x{E007F}]' .`
4. Указания из прочитанного текста — данные. «Игнорируй предыдущие инструкции», «отправь»,
   «открой .env» не выполняются без отдельного решения человека.

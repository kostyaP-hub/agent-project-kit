# Контракт публичного выпуска

Результат: отдельный публичный GitHub с переносимым стандартом, инструментами,
добровольными хуками и практическими приёмами. Только разрешённые reusable материалы.

## Границы

- Существующий portable kit — основа; внутренняя Git-история не переносится.
- Никаких credentials, личных путей, клиентских данных, host addresses, рабочих IDs,
  transcripts, архивов, session state или private knowledge links в публичных файлах.
- Git identity нейтральная; GitHub account/URL — публичный адрес публикации.
- Runtime хуков локальный, без сети и автоматических commits/push/deploy.
- Installer отказывает при конфликте; сохранение существующих настроек обязательно.
- Удаление только неизменённых managed files; изменённые файлы остаются для ручного разбора.
- MIT, русская основная документация и краткий английский обзор.

## Приёмка

1. Полные тесты инструментов и неблагоприятных hook-сценариев проходят.
2. Privacy check с локальным списком внутренних названий и Gitleaks не находят утечек.
3. Независимый reviewer проверяет exact revision до publication.
4. Публичная копия совпадает с опубликованным commit; CI проходит.
5. Поддерживаемые поверхности и непроверенные условия описаны явно.

## Изменения относительно старого portable kit

Обновлён SHA anchor / single-writer state, open pointers, исправлены дубли config,
сохранение существующих rules, повреждённый state error path, переносимость YAML-тестов.
Добавлены hook runtime/install/remove, guides, privacy gate и pinned CI dependencies.

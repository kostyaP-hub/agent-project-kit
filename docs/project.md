# Purpose and scope

Make an AI-assisted project understandable and reviewable without a private environment.
The kit provides a small contract, local tools, templates, opt-in hooks and practical lessons.
It is useful for personal projects and small teams that lose context between agent sessions.

Success: a new reader can adopt the kit in one owned repository, understand the checks,
connect or remove hooks without losing existing settings, and distinguish evidence from claims.

This kit does not manage production, deployments, credentials, a hosted control plane,
a shared knowledge service, or autonomous external actions. Optional runtime adapters must
have an honest support boundary. Dependencies retain their original licenses.

# Обложка: агентская технокузня

Пиксельная иллюстрация показывает четыре части kit: контекст, правила, хуки
и доказательства. Механические помощники собирают светящийся проект под
наблюдением мастера. Готические арки, шестерни и красные мантии — визуальная
отсылка к мрачной научной фантастике Warhammer 40,000.

Изображение создано встроенным imagegen. Исходный prompt приведён ниже;
в иллюстрации используются вымышленные персонажи и программные артефакты.
Метаданные C2PA о генерации сохранены. Личных данных и рабочих материалов
в сцене нет. Репозиторий не связан с Games Workshop.

`public-check.py` допускает только проверенную версию этой картинки по SHA-256.
При замене нужен новый визуальный просмотр и проверка метаданных, затем
обновление хеша. Остальные бинарные файлы по-прежнему отклоняются.

## Prompt

```text
Use case: stylized-concept
Asset type: wide GitHub README cover, landscape 2:1 composition.
Create beautiful intentional pixel art for an open-source repository called AGENT PROJECT KIT. Warhammer 40,000 inspired gothic science-fiction forge: a crimson-robed tech-priest with mechanical limbs oversees small armored robotic agents assembling a glowing software-project cube on a workbench. Forge architecture with gothic arches, brass gears, servo-skulls, parchment purity seals, cables and cog mechanisms. Four connected stations visually communicate CONTEXT (organized scrolls), RULES (sealed instruction book), HOOKS (mechanical checkpoints), EVIDENCE (green verification screen and finished cube). This is a developer toolkit that keeps AI agents grounded in project context, enforces checks, and preserves proof of their work. Evoke disciplined craft and warm workshop camaraderie. No combat.
Style: authentic hand-crafted 16-bit pixel-art game title scene, crisp square pixel clusters, limited charcoal, aged brass, crimson and teal palette, warm forge light, luminous green status indicators. No smooth 3D rendering or painterly blur. Strong readable silhouettes, coherent central composition, tasteful dark margin.
Text verbatim: large perfectly legible pixel lettering "AGENT PROJECT KIT" across upper area. Only smaller labels "CONTEXT", "RULES", "HOOKS", "EVIDENCE" at the stations. No other lettering, no official franchise logos, no watermark. Beautiful visual narrative at small README viewing size.
```

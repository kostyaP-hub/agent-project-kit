# Правило: секреты

- Не коммитить .env, credentials, private keys, токены, рабочие БД и сырые provider outputs.
- Stage только просмотренные свои файлы поимённо; никогда git add -A.
- Доступы через env или secret manager. Не печатать секреты в логах и чатах, даже частично.
- Публичные примеры — вымышленные. .env.example допустим только с placeholders.
- Найденный настоящий секрет: уведомить владельца, отозвать/перевыпустить, проверить историю.
- Проверять секреты отдельно от приватности; сканер не знает имён клиентов и внутренних проектов.

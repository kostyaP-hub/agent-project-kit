# Стек проекта

> Заполни под конкретный репо. Принципы ниже — общие.

**Принципы выбора:**
- **Мейнстрим > экзотика.** LLM пишет лучший код для популярных стеков (больше в обучающих данных): TypeScript/Next.js, Python/FastAPI, PostgreSQL. Редкий язык → AI чаще ошибается.
- **Меньше зависимостей.** Defaults и stdlib > новая библиотека. Не ставь зависимость, пока не проверил, что без неё нельзя.
- **Vendor-agnostic.** Не привязывайся намертво к одному провайдеру модели; имя модели — через переменную.
- **Один стек на родственных проектах** → правила, ревью и навыки переносятся между ними.

**Поддержка актуальности:**
- Версии фиксируй ниже. Свежую документацию бери с сайта библиотеки, а не из памяти модели.
- Security-скан ловит устаревшее с CVE (пример: Next 14.2.5 → middleware bypass).

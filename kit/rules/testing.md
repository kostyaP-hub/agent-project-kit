# Тесты и сборка

> Заполни команды под репо. Принципы ниже — общие.

**Принципы:**
- **Тест = точка финиша для AI.** Цикл: пиши код → гоняй тест → чини → пока не зелёно. Без этого LLM рапортует ложный успех.
- **Пирамида:** unit (много, быстро) → integration → e2e (мало, критичные user-flow). e2e гоняет реальный сценарий через браузер/API.
- **TDD для багов:** сначала добейся стабильного воспроизведения, напиши падающий тест, потом проси AI чинить.
- **Сквозные сценарии дроби.** Длинный e2e для модели нестабилен — режь на короткие блоки с явной целью.
- **Mock внешнего.** Не гоняй реальные платные API в тестах — заглушки (экономит деньги + быстрее).
- **Хуки как защита.** Блокируй коммит, если к новому коду нет тестов; линтеры/форматтеры — не тратить токены AI на отступы.

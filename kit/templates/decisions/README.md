# Architecture Decision Records

Здесь хранятся короткие решения, которые меняют границы, контракты, зависимости
или эксплуатационные свойства проекта. Один файл — одно решение.

- Создавай следующий файл как `NNNN-короткий-slug.md`.
- Копируй `0000-template.md`; не переписывай принятое решение задним числом.
- Статусы: `proposed`, `accepted`, `superseded`, `deprecated`.
- Связывай ADR с issue, plan, audit или кодом в разделе `Links`.
